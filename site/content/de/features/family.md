## Mitglieder und Gruppen

Mitglieder und frei benannte Gruppen wie „Eltern“ oder „Kinder“. Neue Mitglieder kommen per Einladung dazu – als Code oder QR-Code.

{{< scene name="invite" height=620 >}}Eine Einladung mit QR-Code.{{< /scene >}}

## Teilen

Für jede Liste, jeden Kalender und jede Seite: *lesen*, *abhaken* oder *mitschreiben* – für einzelne Personen oder Gruppen. Aufgaben und Termine erben die Freigabe ihrer Liste oder ihres Kalenders, und wer zuständig ist, sieht die Aufgabe automatisch.

{{< scene name="sharing" height=480 >}}Die Freigabe einer Liste.{{< /scene >}}

## Keine Rollen

Alle Mitglieder haben dieselben Funktionen. Der Admin verwaltet den Server; in der App sieht er nur, was ihm gehört oder mit ihm geteilt ist.

## Oma und andere

Ein Konto mit einzelnen geteilten Kalendern und Seiten – oder ohne Konto eine ICS-Adresse für ihren eigenen Kalender.

## So geht's

{{< steps id="familie-einladen" title="Die Familie einladen" >}}
*Du brauchst:* einen Server und das Admin-Konto.

1. Öffne **Konto → Familie** und tippe auf **Neues Mitglied**.
2. Gib optional einen Namen ein, wähle Gruppen und wie lange die Einladung gilt, dann **Einladung erstellen**.
3. Zeig den QR-Code oder gib den Code weiter.
4. Die eingeladene Person installiert Hiwiski, scannt den QR-Code mit der Kamera ihres Handys und wählt Namen und Passwort. Ohne Kamera tippt sie in der App auf **Einladung einlösen** und gibt den Code ein.

Eine Einladung, die noch niemand eingelöst hat, ziehst du unter **Konto → Familie** mit dem ✕ in ihrer Zeile zurück: Ihr Code funktioniert dann nicht mehr.
{{< /steps >}}

{{< steps id="wer-sieht-was" title="Wer sieht was: Teilen mit Gruppen und Stufen" >}}
1. Lege unter **Konto → Familie** Gruppen an, zum Beispiel „Eltern“ und „Kinder“.
2. Öffne eine Liste, einen Kalender oder eine Seite und tippe in der Infoleiste auf **Freigabe**.
3. Füge Personen oder Gruppen hinzu und wähle die Stufe: *lesen*, *abhaken* oder *mitschreiben*.
4. Was in einer Liste oder einem Kalender steckt, folgt automatisch.
{{< /steps >}}

{{< steps id="konto-fuer-kind" title="Ein Konto für ein Kind" >}}
1. Lade das Kind ein, wie oben beschrieben.
2. Teile ihm, was es sehen soll – etwa die Ämtchen mit *abhaken* und den Familienkalender mit *lesen*.
3. Alles andere bleibt für das Kind unsichtbar, bis du es teilst.
{{< /steps >}}

## Gut zu wissen

- Wer Zugriff auf den Server selbst hat (Docker, die Datenbank), kann technisch alles sehen – wie bei jedem selbst gehosteten Dienst.
- Ohne Server gibt es kein Teilen: Das Gerät ist eine Familie aus einer Person.
