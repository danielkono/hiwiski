## Das Start-Board

Kacheln für Kalender, Woche, Listen und Boards. Jedes Familienmitglied richtet sein eigenes ein. Eine einzelne Liste lässt sich direkt auf der Kachel abhaken.

{{< scene name="start-board" live=true height=560 >}}Das Start-Board der Beispielfamilie.{{< /scene >}}

## Das Wandtablet

Ein Dashboard pro Mitglied, im Browser unter einer eigenen Adresse: ohne Anmeldung, ohne App, mit hohem Kontrast und großer Schrift. Der Bildschirm bleibt an, und das Board aktualisiert sich selbst.

{{< scene name="dashboard" height=500 >}}Das Dashboard auf dem Wandtablet.{{< /scene >}}

## Die Kacheln

Uhr, Kalender, Woche, Aufgabenlisten, Einkaufsliste, Kanban-Board, Rezept des Tages, Wiki-Seite und Notiz.

## So geht's

{{< steps id="start-board-einrichten" title="Das eigene Start-Board einrichten" >}}
1. Tippe auf dem Start-Board auf **Start anpassen**.
2. Füge mit **+ Kalender** oder **+ Aufgaben** Kacheln hinzu.
3. Tippe auf eine Kachel, um sie einzustellen: welche Kalender, welche Listen, wie breit.
4. **Fertig**. Nur dein eigenes Start-Board ändert sich.

{{< scene name="start-board" live=true height=560 >}}Probier es aus: Füge eine Kachel hinzu.{{< /scene >}}
{{< /steps >}}

{{< steps id="wandtablet" title="Ein Wandtablet einrichten" >}}
*Du brauchst:* einen Server.

1. Lege für das Tablet ein eigenes Mitglied an, zum Beispiel „Flur“, und teile ihm die Listen und Kalender, die es zeigen soll.
2. Melde dich als dieses Mitglied an und öffne **Konto → Dashboard**. Stelle die Spaltenzahl ein und ordne die Kacheln an.
3. Oben steht die Adresse des Dashboards. Öffne sie im Browser des Tablets, zum Beispiel über **Als QR anzeigen**.
4. Stelle den Browser auf Vollbild. Das Board hält den Bildschirm wach.

Geht das Tablet verloren oder wurde die Adresse weitergegeben: Mit **Neu erzeugen** ist die alte Adresse sofort ungültig.
{{< /steps >}}

## Gut zu wissen

- Wer die Adresse kennt, sieht das Board. Sie läuft nicht ab und lässt sich jederzeit neu erzeugen.
- Ist der Server nicht erreichbar, zeigt das Tablet den letzten Stand mit „zuletzt aktualisiert 14:32“.
- Ohne Server gibt es kein Wandtablet.
