## The start board

Tiles for calendar, week, lists and boards. Every member arranges their own. A single list can be ticked off right on its tile.

{{< scene name="start-board" live=true height=560 >}}The sample family's start board.{{< /scene >}}

## The wall tablet

One dashboard per member, in the browser under an address of its own: no sign-in, no app, with high contrast and large type. The screen stays on, and the board updates itself.

{{< scene name="dashboard" height=500 >}}The dashboard on the wall tablet.{{< /scene >}}

## The tiles

Clock, calendar, week, task lists, shopping list, Kanban board, recipe of the day, wiki page and note.

## How to

{{< steps id="arrange-start-board" title="Arrange your start board" >}}
1. On the start board tap **Customise start**.
2. Add tiles with **+ Calendar** or **+ Tasks**.
3. Tap a tile to set it up: which calendars, which lists, how wide.
4. **Done**. Only your own start board changes.

{{< scene name="start-board" live=true height=560 >}}Try it: add a tile.{{< /scene >}}
{{< /steps >}}

{{< steps id="wall-tablet" title="Set up a wall tablet" >}}
*You need:* a server.

1. Create a member of its own for the tablet, for example "Hallway", and share with it the lists and calendars it should show.
2. Sign in as that member and open **Account → Dashboard**. Set the number of columns and arrange the tiles.
3. The dashboard's address is at the top. Open it in the tablet's browser, for example through **Show as QR**.
4. Put the browser in full screen. The board keeps the screen awake.

If the tablet is lost or the address has been passed on: **Regenerate** makes the old address invalid at once.
{{< /steps >}}

## Good to know

- Whoever knows the address sees the board. It does not expire and can be regenerated at any time.
- If the server cannot be reached, the tablet keeps the last state with "last updated 14:32".
- Without a server there is no wall tablet.
